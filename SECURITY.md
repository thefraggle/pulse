# Security Policy

## Supported Versions

We actively support and provide security updates for the latest stable release of Pulse.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| 1.2.x   | :x:                |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Pulse, please **do not** report it in a public GitHub issue.

Instead, please send an email to:
**daniel.notthoff@gmail.com**

Please include:
* A description of the vulnerability.
* Steps or a proof-of-concept to reproduce the issue.
* Any potential mitigation steps you have identified.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch.
